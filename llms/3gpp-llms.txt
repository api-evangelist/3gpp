# 3GPP

> The 3rd Generation Partnership Project writes the technical specifications for the world's mobile networks — GSM, UMTS, LTE, 5G and the ongoing 6G work — through seven regional Organizational Partners (ARIB, ATIS, CCSA, ETSI, TSDSI, TTA, TTC). It sells nothing to developers and runs no developer programme, but since Release 15 it has published the RESTful Service Based Architecture, the SCEF/NEF northbound exposure APIs and the SA5 management services as machine readable OpenAPI 3.0, free of charge and without a login, in a public GitLab at forge.3gpp.org.

Important: 3GPP hosts no callable API. Every `servers` entry in its OpenAPI documents is an `{apiRoot}` (or `{MnSRoot}`) template that a mobile network operator fills in when it deploys the interface. There is no portal, no API key, no sandbox and no base URL to point an agent at. The developer facing abstraction over these interfaces is CAMARA and GSMA Open Gateway, not 3GPP itself.

## Specifications
- [OpenAPI documents in this repository](https://github.com/api-evangelist/3gpp/tree/main/openapi): 116 OpenAPI 3.0 documents, 465 operations, harvested from forge.3gpp.org
- [5G_APIs on forge.3gpp.org](https://forge.3gpp.org/rep/all/5G_APIs): 5G core Service Based Interfaces, NEF/SCEF northbound APIs and CAPIF, one branch per Release (REL-15 through REL-20)
- [Management and Orchestration APIs (SA5 MnS)](https://forge.3gpp.org/rep/sa5/MnS): provisioning, performance, fault and data reporting management services
- [Specification archive](https://www.3gpp.org/ftp/Specs/archive/): every version of every Technical Specification and Technical Report
- [Specifications by series](https://www.3gpp.org/specifications-technologies/specifications-by-series)

## Key specification families
- TS 29.500 / TS 29.501: technical realization and design guidelines for the Service Based Interface (HTTP/2, JSON, RFC 7807 problem details, 3gpp-Sbi-* custom headers)
- TS 29.122 / TS 29.522: northbound exposure APIs (SCEF and NEF) — monitoring events, QoS on demand, NIDD, device triggering, MBS, edge, time sync
- TS 29.222: CAPIF, the Common API Framework — invoker onboarding, service discovery, security, auditing and logging
- TS 29.510 / TS 29.512 / TS 29.514 / TS 29.520: NRF, policy control and NWDAF analytics
- TS 28.532 and the 28-series: management services and the network resource models
- TS 29.571: the 5G core common data types every other document $refs
